# 01. Visão Geral do Produto

Este diretório armazena os documentos estratégicos e de alto nível que definem o propósito do software.

## O que documentar nesta pasta:
1. **Contexto e Problema**: Descrição clara da dor que o sistema se propõe a resolver.
2. **Proposta de Valor e Objetivos**: Benefícios centrais esperados com o desenvolvimento da aplicação.
3. **Público-Alvo e Personas**: Perfis detalhados dos usuários que interagem com o sistema (operadores, clientes, administradores).
4. **Escopo do Projeto**:
   - **In-Scope**: Funcionalidades e entregas que fazem parte da versão atual.
   - **Out-of-Scope**: O que NÃO será desenvolvido neste momento para evitar escopo inflado.
5. **Glossário**: Definições dos termos técnicos e jargões de negócio do domínio.
