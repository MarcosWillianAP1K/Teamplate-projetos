# 05. Sprints e Evolução do Produto

Este diretório armazena o histórico de evolução, notas de lançamento e roadmap do produto.

## O que documentar nesta pasta:
1. **Histórico de Releases e Changelog**: Registro cronológico de novas funcionalidades, correções de bugs e alterações arquiteturais.
2. **Roadmap de Próximas Sprints**: Planejamento trimestral ou por sprint das prioridades técnicas e de negócio.
3. **Decisões Arquiteturais Registradas (ADRs)**: Documentação de escolhas tecnológicas importantes (ex: adoção de PostgreSQL vs Supabase, bibliotecas de cache ou mensageria).
4. **Relatórios de Retrospectiva**: Lições aprendidas e planos de ação para melhoria contínua da equipe.
