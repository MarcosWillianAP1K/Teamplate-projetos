# 02. Engenharia de Requisitos

Este diretório concentra a especificação detalhada das funcionalidades e restrições técnicas do sistema.

## O que documentar nesta pasta:
1. **Requisitos Funcionais (RF)**: Comportamentos que o sistema deve executar (ex: `RF-001: Autenticação via e-mail e senha`, `RF-002: Criação de pedidos`).
2. **Requisitos Não-Funcionais (RNF)**: Critérios de qualidade e limites operacionais (ex: `RNF-001: Latência HTTP abaixo de 200ms`, `RNF-002: Criptografia de senhas com bcrypt`).
3. **Regras de Negócio (RN)**: Políticas obrigatórias que condicionam o funcionamento das rotas e serviços.
4. **Histórias de Usuário (User Stories)**: Especificações no padrão ágil: *"Como [perfil], desejo [funcionalidade] para que [valor de negócio]"*.
5. **Critérios de Aceite (Definition of Done - DoD)**: Checklists obrigatórios para considerar uma funcionalidade pronta para produção.
